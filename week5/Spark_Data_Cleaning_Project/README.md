# Week 5 - PySpark Data Cleaning and Aggregation

## Objective

Perform data cleaning and aggregation using PySpark DataFrames.

## Operations Performed

- Loaded CSV dataset
- Removed duplicate records
- Handled null values
- Filtered records
- Added derived column (sales_level)
- Grouped data using category
- Calculated total and average sales

## Technologies Used

- Python
- PySpark
- Apache Spark

## Run the Project

```bash
pip install -r requirements.txt
py spark_cleaning.py
```
