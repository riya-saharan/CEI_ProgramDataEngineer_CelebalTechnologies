# Week 7 - Delta Lake MERGE Implementation Assignment

## Objective

The objective of this assignment is to perform basic data cleaning and transformation using Python and Pandas on the Superstore dataset.

## Dataset Used

The dataset used for this assignment is the Superstore dataset.

File used:

- Sample - Superstore.csv

## Tasks Performed

- Loaded the CSV dataset into a Pandas DataFrame
- Explored the dataset using head, tail, shape, columns, and data types
- Checked missing values in all columns
- Handled missing values using dropna
- Removed duplicate rows from the dataset
- Performed basic filtering where Sales > 100
- Selected important columns from the dataset
- Created a new column named Price using Sales / Quantity
- Created a new column named total_amount using Price \* Quantity
- Saved the cleaned dataset as cleaned_superstore.csv

## Final Dataset Shape

The final cleaned dataset contains:

- 9994 rows
- 23 columns
